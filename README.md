# Permanecer

Sitio web de Permanecer, centro de psicoterapia virtual. Psicoterapia basada en evidencia: DBT, ACT, mindfulness y trauma. Online en todo el mundo y presencial en Buenos Aires.

`index.html` es una página one-page autocontenida, construida con el manual de marca de Permanecer: tipografía League Spartan, paleta naranja / bordó / petróleo, degradados de sol y arcos finos. Sin dependencias ni build: se abre directo en el navegador.

En producción: https://vidaplenapsi.netlify.app
